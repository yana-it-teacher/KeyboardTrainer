# 🚀 Клавіатурний тренажер для дітей «Спритні пальчики» (Smart Fingers)

Яскрава, інтерактивна та повністю автономна десктопна програма для дітей, яка навчає сліпому десятипальцевому друку на клавіатурі в легкій ігровій формі.

---

## 🌟 Головні можливості для дітей

1. **Двомовність**:
   - 🇺🇦 **Українська розкладка (ЙЦУКЕН)** — підтримка всіх літер: `і`, `ї`, `є`, `ґ`, апострофа тощо.
   - 🇬🇧 **Англійська розкладка (QWERTY)**.
   - Перемикання в 1 клік кнопкою у верхньому правому куті.

2. **Інтерактивна віртуальна клавіатура з підказками пальчиків**:
   - Кожна клавіша пофарбована у колір відповідного пальця руки (10-пальцевий метод друку).
   - Активна потрібна клавіша підсвічується **яскравим золотим сяйвом**.
   - Підказка текстом зверху: наприклад, `👉 Палець: Лівий вказівний`.
   - Миттєва анімація натискання: зелений спалах при правильному натисканні, червоний — при помилці.

3. **4 захоплюючі навчальні режими**:
   - 🔤 **Літери та ряди**:
     - *Домашній ряд* (Ф І В А / О Л Д Ж)
     - *Верхній ряд* (Й Ц У К Е Н...)
     - *Нижній ряд* (Я Ч С М И Т...)
     - *Цифри та знаки*
     - *Весь алфавіт упереміш*
   - 🐱 **Веселі слова**:
     - Дитячі слова з яскравими емодзі (кіт 🐱, сонце ☀️, яблуко 🍎, ракета 🚀, веселка 🌈 тощо).
     - Покроковий ввід літер: надруковані літери стають зеленими, наступна підсвічується.
   - ☄️ **Аркадна гра «Падаючі літери»**:
     - Літери повільно опускаються згори екрану, як метеорити.
     - Дитина має встигнути натиснути правильну клавішу, перш ніж метеорит торкнеться низу.
     - Очки, серії влучань та 3 серця життів.
   - 📖 **Маленький казкар (Речення)**:
     - Прості добрі речення про дружбу, навчання, природу та космос.

4. **Гейміфікація та заохочення**:
   - Веселі аватарки (🚀, 🐱, 🐶, 🦁, 🐼, 🦄, 🦊, 🤖).
   - Лічильник зірочок ⭐ та вогняна серія успіху (`🔥 Серія: 10`).
   - Підбадьорливі репліки («Молодець! 👏», «Чудово! 🌟», «Точно в ціль! 🎯»).
   - Приємні звукові сигнали успіху та фанфари (з можливістю вимкнення кнопкою 🔊/🔇).
   - 🏆 **Таблиця рекордів та досягнень** із збереженням результатів кількох учнів.

## 💻 Як запустити на ІНШИХ комп'ютерах (без встановлення Python)

Програма вже скомпільована в автономний файл, який **не вимагає встановлення Python чи будь-яких додаткових програм**:

1. Відкрийте папку:
   ```
   KeyboardTrainer\dist\
   ```
2. Знайдіть файл:
   ```
   KeyboardTrainer.exe
   ```
3. **Скопіюйте цей файл на флешку (USB) або надішліть через Telegram / Google Диск / локальну мережу класу**.
4. На будь-якому іншому комп'ютері під керуванням Windows 10/11/8/7 просто двічі клікніть по `KeyboardTrainer.exe`.
5. Програма запуститься миттєво! Усі налаштування, рекорди та прогрес учнів автоматично зберігаються у файл `progress.json` поруч із програмою.

## 🛠️ Як змінити код або зібрати новий EXE

Якщо ви хочете відредагувати завдання, додати нові слова чи рівні:
1. Вихідний код знаходиться у файлі [`main.py`](file:///e:/%D0%9F%D1%80%D0%BE%D1%94%D0%BA%D1%82%D0%B8/KeyboardTrainer/main.py).
2. Запустити напряму для перевірки:
   ```bash
   py -3.13 main.py
   ```
3. Для повторної збірки в новий `.exe` просто запустіть подвійним кліком:
   ```cmd
   build_exe.bat
   ```
   або виконайте команду:
   ```bash
   py -3.13 -m PyInstaller --noconsole --onefile --icon=icon.ico --name="KeyboardTrainer" main.py
   ```
   Оновлений файл з'явиться в папці `dist\KeyboardTrainer.exe`.
