# 🚀 Клавіатурний тренажер для дітей «Спритні пальчики» (Smart Fingers)

Яскрава, інтерактивна та повністю автономна десктопна програма для дітей, яка навчає сліпому десятипальцевому друку на клавіатурі (малих і великих літер), спеціальним комбінаціям української мови (зокрема літери **ґ / Ґ**) та найважливішим гарячим клавішам у легкій ігровій формі.

---

## 🌟 Головні можливості програми

1. **Спеціальна підтримка української літери «ґ» та «Ґ»**:
   - ⌨️ **Два способи введення**:
     1. **Окрема фізична кнопка [ ґ ]** (якщо вона є на клавіатурі).
     2. **Стандартна комбінація Windows [ Ctrl ] + [ Alt ] + [ г ]** (або правий `AltGr + г`) — спеціально для комп'ютерів, де немає окремої кнопки `ґ`!
     3. Для великої літери **Ґ**: `[ Shift ] + [ ґ ]` **АБО** `[ Ctrl ] + [ Alt ] + [ Shift ] + [ г ]`!
   - 💡 **Наочна підказка на екрані**:
     - Якщо завдання ввести літеру `ґ`: виводиться плашка:
       `👉 Кнопка [ ґ ]   АБО комбінація:   [ Ctrl ] + [ Alt ] + [ г ] (AltGr + г)`
     - На віртуальній клавіатурі **одночасно підсвічуються як клавіша ґ, так і клавіші [Ctrl], [Alt], [Г]**!
   - 📚 **Спеціальні слова з літерою Ґ**:
     - *Ґава 🐦, Ґудзик 🔘, Дзиґа 🌀, Аґрус 🍈, Ґанок 🏡*.
   - 🎯 **У режимі «Гарячі клавіші» додано окрему картку-тренажер**:
     - `Ctrl + Alt + Г` — секретна комбінація для друку літери «ґ» без окремої кнопки.

2. **Введення як малих, так і великих літер (з підказками комбінацій)**:
   - 🔤 **Малі літери (а, б, в...)**:
     - Відображається підказка: `👉 Звичайна клавіша: [ а ] (без Shift)`.
     - Якщо випадково затиснуто Shift: `⚠️ Потрібна МАЛА літера 'а'! Відпусти [Shift]!`.
   - 🔠 **Великі літери (А, Б, В...)**:
     - Бейдж: `⭐ ВЕЛИКА ЛІТЕРА (ПОТРІБЕН SHIFT!)`.
     - Точна комбінація: `👉 Комбінація: [ Shift ]  +  [ а ]`.
     - Підказка руки: `👉 Правий мізинець на [Shift] + Лівий вказівний на [а]`.
     - При затисканні `Shift` клавіша на екрані спалахує зеленим, а всі літери на віртуальній клавіатурі стають великими.
   - 🔀 **Режими вибору регістру**:
     - *Малі та великі (Упереміш)*, *Лише малі*, *Лише великі*.

3. **Двомовність**:
   - 🇺🇦 **Українська розкладка (ЙЦУКЕН)** — підтримка всіх літер: `і`, `ї`, `є`, `ґ`, апострофа тощо.
   - 🇬🇧 **Англійська розкладка (QWERTY)**.
   - Перемикання в 1 клік кнопкою у верхній панелі.

4. **5 навчальних режимів**:
   - 🔤 **Літери та ряди**: тренування малих та великих літер за рядами (включаючи `ґ` у нижньому ряду).
   - 🐱 **Веселі слова**: слова з великої літери та з літерою ґ (*Кіт 🐱, Ґава 🐦, Ґудзик 🔘, Сонце ☀️, Яблуко 🍎*).
   - ⚡ **Гарячі клавіші (Hotkeys)**:
     - 🎯 *Тренажер комбінацій*: `[ Ctrl ] + [ Alt ] + [ Г ]` (літера ґ), `[ Shift ] + [ Літера ]`, `[ Ctrl ] + [ C ]`, `[ Ctrl ] + [ V ]`, `[ Ctrl ] + [ Z ]`, `[ Ctrl ] + [ S ]`, `[ Win ] + [ Shift ] + [ S ]` тощо.
     - ❓ *Вікторина знавця (Quiz)*.
     - 📚 *Довідник гарячих клавіш*.
   - ☄️ **Аркадна гра «Падаючі літери»**: падають малі та великі зіркові літери (включаючи `ґ` та `Ґ`).
   - 📖 **Речення**: друкування речень про природу, космос, дружбу та речень зі словами на літеру ґ.

5. **Гейміфікація та звукові ефекти**:
   - 8 аватарок на вибір учня (🚀, 🐱, 🐶, 🦁, 🐼, 🦄, 🦊, 🤖).
   - Зірочки ⭐, комбо-серії (`🔥 Серія: 10`), приємні звукові сигнали та фанфари (кнопка 🔊/🔇).
   - 🏆 **Таблиця рекордів**: зберігає досягнення всіх учнів.

## 💻 Як запустити на ІНШИХ комп'ютерах (без встановлення Python)

1. Відкрийте папку:
   ```
   KeyboardTrainer\dist\
   ```
2. Знайдіть файл:
   ```
   KeyboardTrainer.exe
   ```
3. Скопіюйте файл на USB-флешку або надішліть через месенджер / диск / мережу.
4. На будь-якому іншому комп'ютері під керуванням Windows 10/11/8/7 відкрийте `KeyboardTrainer.exe` подвійним кліком.
