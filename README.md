# 🚀 Клавіатурний тренажер для дітей «Спритні пальчики» (Smart Fingers)

Яскрава, інтерактивна та повністю автономна десктопна програма для дітей, яка навчає сліпому десятипальцевому друку на клавіатурі та найважливішим гарячим клавішам у легкій ігровій формі.

---

## 🌟 Головні можливості програми

1. **Двомовність**:
   - 🇺🇦 **Українська розкладка (ЙЦУКЕН)** — підтримка всіх літер: `і`, `ї`, `є`, `ґ`, апострофа тощо.
   - 🇬🇧 **Англійська розкладка (QWERTY)**.
   - Перемикання в 1 клік кнопкою у верхній панелі.

2. **Інтерактивна віртуальна клавіатура з підказками пальчиків**:
   - **Кольорове зонування (10-пальцевий метод)**: кожна клавіша пофарбована у колір пальця, яким її слід натискати.
   - **Реалістичний вигляд з модифікаторами**: містить `Ctrl`, `Alt`, `Win`, `Shift` та `Пробіл`.
   - **Підсвічування потрібних клавіш**: активна літера або комбінація підсвічуються яскравим сяйвом.
   - **Мульти-підсвітка та реакція на затискання**: коли дитина затискає `Ctrl` або `Alt`, клавіша на екрані спалахує зеленим кольором!
   - **Текстова підказка руки**: наприклад, `👉 Ліва рука: мізинець на [Ctrl], вказівний на [C]`.

3. **5 навчальних режимів**:
   - ⚡ **НОВЕ! Гарячі клавіші (Hotkeys)**:
     - 🎯 **Тренажер комбінацій**: велика наочна картка, живий індикатор затискання модифікаторів у реальному часі, покрокове навчання та інтерактивна міні-пісочниця (можна скопіювати зразок за допомогою `Ctrl+C` і вставити його в поле за допомогою `Ctrl+V`!).
     - ❓ **Вікторина знавця (Quiz)**: захоплюючі інтерактивні запитання («Як повернути випадково видалене?», «Як зберегти роботу?»), відповіді можна вибирати мишкою або натискати саму комбінацію на клавіатурі!
     - 📚 **Довідник**: повний ілюстрований список корисних гарячих клавіш із поясненням та пальчиковими підказками.
   - 🔤 **Літери та ряди**: тренування за рівнями (*Домашній базовий ряд ФІВА/ОЛДЖ*, *Верхній ряд*, *Нижній ряд*, *Цифри та знаки*, *Увесь алфавіт*).
   - 🐱 **Веселі слова з малюнками**: слова супроводжуються милими емодзі (кіт 🐱, сонце ☀️, яблуко 🍎, ракета 🚀, веселка 🌈).
   - ☄️ **Аркадна гра «Падаючі літери»**: букви повільно падають, як метеорити; дитині треба встигнути збити їх правильною клавішею. Є очки, серця життів та рекорди.
   - 📖 **Речення**: друкування простих добрих povчальних речень.

4. **Гейміфікація та звукові ефекти**:
   - 8 аватарок на вибір учня (🚀, 🐱, 🐶, 🦁, 🐼, 🦄, 🦊, 🤖) та зміна імені.
   - Зірочки ⭐, комбо-серії (`🔥 Серія: 10`), приємні звукові сигнали та фанфари (кнопка 🔊/🔇).
   - 🏆 **Таблиця рекордів**: зберігає прогрес кожного учня, точність, рекорд у грі та кількість освоєних гарячих клавіш.

## 💻 Як запустити на ІНШИХ комп'ютерах (без встановлення Python)

Програма вже скомпільована в автономний файл, який **не вимагає встановлення Python чи будь-яких бібліотек**:

1. Відкрийте папку:
   ```
   KeyboardTrainer\dist\
   ```
2. Знайдіть файл:
   ```
   KeyboardTrainer.exe
   ```
3. **Скопіюйте цей файл на флешку (USB) або надішліть через Telegram / Google Диск / локальну мережу**.
4. На будь-якому іншому комп'ютері під керуванням Windows 10/11/8/7 двічі клікніть по `KeyboardTrainer.exe`.
5. Програма запускається миттєво! Усі рекорди та налаштування учнів автоматично зберігаються поруч у файлі `progress.json`.
